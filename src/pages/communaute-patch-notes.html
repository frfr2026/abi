Comment lire un patch (méthode NEXUS)

  1. La première ligne du changelog = l'intention du patch (event ? balance ? fix ?).
  2. Isole ce qui touche ton jeu : caps, armes que tu mains, deadlines d'événements.
  3. Croise avec tes pages : une nerf d'arme → tier list · un event → calendrier · un item → valeur.
  4. Note la date — le méta a une date de péremption (nos pages affichent la leur).
