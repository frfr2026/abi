D'où viennent les tags — les playerbots

🤖 Repérer un porteur de tag

Les tags tombent des playerbots : des IA déguisées en opérateurs (kits « quick kit style » mais jamais de vrai kit) dans les difficultés/bas niveaux. Les scavs n'en portent pas. Avec l'habitude, leur équipement basique se repère en une seconde.

Payer son exfil — la règle found-in-raid

  • ⚠️ Pour les extractions à tag : le tag doit être trouvé pendant le raid — rien depuis ta stash (« cannot be brought back in »).
  • Les exfils spéciaux des grandes cartes (Port, Noan… via clé/tag) font partie de l'économie des exfils optionnels — garde 1-2 slots de tags dans ton rig quand tu les vises.
  • Habitude de pro : ramasse toujours les tags des playerbots — même sans exfil en vue, ils serviront (mission, vitrine, vente).

La vitrine & le palier 500

  1. Au hideout, la table à tags s'affiche avec tes trophées — hover pour voir le compteur.
  2. Le compteur se level up en collectionnant — purement cosmétique, mais visible à chaque passage en base.
  3. Palier 500 : extraire 500 tags (ou via Secure Ops) → 3 boîtes de dog tags devant la vitrine. Le trophée final du collectionneur.

Battleforged — le tag à 70k

⚔️ La monnaie des Forbidden

Les Battleforged Dogtags valent 70k Koen en Forbidden (chiffre communautaire S6/S7) — collecter les tags des joueurs que tu tombes devient un side income de haut niveau. Verdict : vend les Battleforged si tu ne collects pas pour la vitrine ; garde les classiques pour les exfils et les 500.
  • Stratégie mixte (recommandée) : tags classiques → stash vitrine/exfils · Battleforged → vente directe.
  • Les appels à « dog tag shop » (skins en échange) ferment les threads : pour l'instant, l'argent ou la vitrine — pas d'échange cosmétique.
