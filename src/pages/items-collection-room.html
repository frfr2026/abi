Les deux systèmes

EspaceContenuRègle clé
🏆 Trophy Room Trophées de Recherche Workbench (formules apprises → blueprints) + rouges spéciaux exposés Secret Document / Utopia : 1 extraction = affiché, non consommé
🗄️ Collection Room Collectibles rouges déposés (Lion, colliers, théières, sculptures, TI Module…) Sauf les étiquettes « operation supplies » — refusées

Les deux espaces remplissent la même fonction psychologique : transformer le loot en preuve. Dans un jeu où la mort efface ton sac, la vitrine est la seule chose qui reste.

Quoi exposer — le catalogue des rouges

  • 📜 Secret Document — le roi : 1 extraction, zéro consommation, valeur d'affichage quasi 24M (vrai cash : 16-17M).
  • 🌌 Utopia — le red de saison (valeur ~4-7M selon rapports), même règle d'affichage sans consommation.
  • 🦁 Les rouges classiques : Lion d'or, collier de gemmes, théière, vase, sculpture majestueuse, TI Module (plus petit red, tie avec le Document).
  • 🔬 Les blueprints de Recherche appris — la vitrine de ta progression Workbench (voir workbench).

Règles pièges à connaître

⚠️ Le tag « operation supplies »

« Gold Bounty collectibles marked as operation supplies cannot be stored in the Collection Room ». Avant de refuser une offre de Contact à 16M « pour l'exposer », vérifie l'étiquette : certains rouges n'iront pas en vitrine.
  • Le Document s'affiche sans être consommé — mais d'autres collectibles de saison peuvent demander une consommation : lis le prompt avant de valider.
  • La valeur affichée ≠ valeur de vente (le Document est l'exemple canonique).
  • Les rouges de stash occupent des slots : la Collection Room libère potentiellement de la place de stash — avantage secondaire réel.
