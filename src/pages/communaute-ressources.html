GitHub & open source

⚠️ Alerte arnaques (nov. 2026) : les repos GitHub qui prolifèrent sous les noms « ABI hack / ESP / aimbot / overlay menu » sont des appâts à malwares (vol de wallet, stealer) et des pièges à bannissement — aucun n'est légitime. Les seuls projets open source à connaître sont les 3 ci-dessous (+ les outils listés plus haut). Jamais de « téléchargement de cheat » : tu perds ton compte et potentiellement tes affaires.
RepoCe que c'est
🐙 imzleep/abibuilderFront d'abibuilder en open source — MIT, Next.js/TS/Supabase
🐙 nicolasaigner/ABI-InteractiveMapsCartes interactives Leaflet (PT-BR), filtres de clés, déployé sur Vercel — inspiré des maps Fandom
🐙 fabiopsyduck/Arena-Breakout-Infinite-Offline-Database (+ ABIDB-WEB)Base de données hors-ligne du jeu + son front web

Ces repos sont la preuve que l'écosystème ABI est buildable : même notre NEXUS (générateur de pages, data JSON, Leaflet à venir) suit cette philosophie d'outils légers et locaux.

FAQ ressources

Hiérarchie : patch notes officiels (Steam/site) → datamine/repo → fansites datés → reddit. Nos pages affichent la date de vérification et citent leurs sources en bas — quand deux sources divergent (ex. valeur du Secret Document), on affiche les deux avec leur contexte.

Les repos GitHub ci-dessus acceptent PR/Issues (ABI-InteractiveMaps le mentionne explicitement). Pour NEXUS : chaque page est un fichier source dans src/pages/ — signale la page et la donnée à corriger.
