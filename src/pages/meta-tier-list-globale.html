Comment lire cette tier list

🧭 Règle d'or

Une tier list ne choisit pas ton arme — ton scénario le fait. Le S sert de défaut, le A de spécialiste, le B de remplissage jouable, le C de niche budgétaire. Croise toujours avec la carte et le mode (caps T4/T5).

Munitions & caps — le tri par mode

  • Normal : ≤ T4 — BP, BS, SS109, M80. Ton T5+ dort ou se vend.
  • Lockdown : ≤ T5 — 7N39, AP, M61, M995 sur les plateformes qui les justifient.
  • Forbidden : libre — le T6 (PPBS) entre en jeu.
  • Technique : top-load (5 premières balles chères) + durabilité adverse = pénétration déterministe (voir balance et munitions).
