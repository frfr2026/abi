📦 Comprendre la squad crate

Chaque niveau élargit le loot distribué au squad à l'ouverture — la crate est un bien commun : plus ta squad farm, plus la caisse collective grossit. Motive l'équipe : le XP de l'un nourrit les autres.

Les étoiles hebdo — la horloge

  1. ⭐ Chaque task d'événement a 3 paliers d'objectifs → 1 étoile par palier (3 max par task).
  2. 📅 Les tasks refreshent lundi 05:00 (UTC+0) — types de tasks tirés aléatoirement.
  3. 🏆 Assez d'étoiles dans la semaine → récompenses correspondantes de la track.
  4. ⚠️ « Unclaimed rewards will not be reissued » — l'étoile non réclamée avant le reset est détruite.

Le Smelter — à quoi sert Lv.3 ?

  • Le Smelter (fonderie) se débloque au niveau 3 de la crate : c'est l'atelier d'événement qui transforme/déblocage des récompenses spéciales (lien avec l'écosystème des formules de saison).
  • Il complète la Recherche Workbench : l'un permanent de saison, l'autre piloté par l'événement Supplies.
  • Priorité de progression : monter la crate jusqu'au Lv.3 dès que possible — chaque semaine sans Smelter = crafts d'événement perdus.

Stratégie hebdo type

  1. Lundi matin (post-reset) : lis les nouvelles tasks — oriente tes raids du jour vers les paliers faciles (1 étoile = 1 palier, souvent un seul objectif simple).
  2. Mil de semaine : raids de loot classiques (XP conteneurs) + un terminal par run (Farm/Tv) — la crate monte en tâche de fond.
  3. Dimanche : récupère tout — dernière étoile non réclamée = zéro réémission.
  4. Croise avec les autres trackers : Halloween (pumpkins) et Warlord (stars de tournoi) ont leurs propres clocks — voir calendrier.

FAQ Supplies Drops 2.0

La Reward Crate est une squad crate — la progression nourrit le loot commun. Jouer groupé accélère les niveaux (loot + kills + terminaux se multiplient).

Les étoiles et récompenses non réclamées sont perdues (pas de réémission) — mais la crate XP, elle, progresse en continu sur la saison. Le vrai risque hebdo = les étoiles, pas la crate.
