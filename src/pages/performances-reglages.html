Upscaling & latence

  • 🎯 DLSS : selon les tests, l'image ressort plus propre que le natif — rare, mais vrai sur ABI. Aucune pénalité de latence notable : ON.
  • 🚫 FSR & TSR : dégradent visiblement l'image selon les testeurs — à éviter si tu as une carte NVIDIA.
  • ⚡ Reflex ON + V-Sync OFF : le duo latence minimale. Avec VRR/G-Sync, plafonne 3 FPS sous le taux de rafraîchissement pour un frame pacing stable sans tearing.
  • 📺 Si tu as des micro-coups avec VRR + Reflex : c'est un réglage de plafond à ajuster, pas un souci matériel (retours communautaires).
  • 🧠 Frame Generation / Interpolation : OFF — la génération d'images ajoute de la latence, inutile dans un FPS compétitif.
  • 📉 Variable Rate Rendering : OFF selon la recommandation compétitive communautaire.

NVIDIA Control Panel & Windows

Panneau de contrôle NVIDIA

  • Power management : Prefer maximum performance
  • Threaded optimization : ON
  • Preferred refresh rate : Highest available
  • Image sharpening : OFF (le jeu a son propre auto-sharpen)
  • CUDA GPUs : toutes

Windows 11

  • Gaming → Game Mode : ON
  • Graphics → exécutable ABI : Haute performance
  • Priorité processus (Gestionnaire des tâches) : Haute pour le jeu, pas le launcher
  • Overlay Steam/Discord : désactivé en raid si tu cherches le max

Référence serveur : 72 tick-rate depuis S6 (upgradé côté Morefun) — les réglages ne changent pas ton hitreg, uniquement ta fluidité et ta lisibilité.

Questions fréquentes

Souvent un plafond : V-Sync, plafond FPS in-game, ou limitation GPU/CPU. Vérifie le panneau NVIDIA (power = max performance), désactive le V-Sync, et regarde si ton CPU plafonne (ABI est léger CPU mais les raids 5-squads chargeent). Les retours « même FPS en 720p et 1080p » signalent un bottleneck non-GPU.
