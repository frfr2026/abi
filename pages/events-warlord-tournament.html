Les règles de l'édition 3

  • ⚔️ Squad-vs-squad ranked — chaque équipe voit le loadout des autres (« every move out in the open »).
  • 💎 Score = valeur de loot — pas seulement les kills : extraire propre compte autant que tuer.
  • 📅 29/10 → 07/12/2026 (UTC+0) — 40 jours, la plus longue fenêtre de S7.
  • 🏆 Rang + missions : les rangs donnent les cosmétiques de palier, les missions donnent les tokens du shop IND70.

📖 Contexte des éditions

Éd. 1 (avr. 2026, S5 Distortion) : debut sur TV Station, lobbies 5 squads. Éd. 2 (août 2026, S6) : stars Team Rank + Personal Eliminations (cap 3/raid). Éd. 3 (S7 Utopia) : Encrypted File multiplier · dog-tag intel · Kill Leader mark.

Features S7 du scoring

  • 🔐 Encrypted File multiplier : les fichiers chiffrés rapportent des points bonus — priorise-les en run de tournoi.
  • 🐕 Dog-tag intel : l'intel via tags de joueurs (nouveau flux de points — voir dog tags).
  • ☠️ Kill Leader mark : la cible marquée = opportunité ou risque — juge selon ton kit.
  • 💎 Rappel : le loot extrait reste le cœur — un raid propre < un kill < les deux.
