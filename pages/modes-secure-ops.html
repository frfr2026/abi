Secure Ops

Sommaire

Règles du mode Cap 600k Conversion Koen Loadouts vs autres modes FAQ
TL;DR : tu gardes tout ton gear porté même en cas d'échec d'extraction — seules les munitions/soins/consommables utilisés sont perdus. La loot convertie en Koen à ~30-40% de sa valeur. Cap d'équipement 600k (valeur portée). Mode idéal : apprendre, tester, missions de saison — pas pour devenir riche.

Les règles du mode

  • 🛡️ Équipement préservé : échec d'extraction = ton gear porté reste intact (arme, armure, casque, rig — même durabilité). Formulation officielle MoreFun : « you won't lose any gear when you fail to extract ».
  • 💸 Ce que tu perds quand même : les munitions tirées, les soins consommés, les lancés utilisés. Chaque raid a donc un coût réel, même « safe ».
  • 💰 Extraction = conversion : tout le loot ramassé est automatiquement converti en Koen (envoyé par mail) — tu ne rapportes pas d'objets physiques.
  • 🚫 Pas de casque de sécurité gratuit : c'est un filet, pas un mode sans conséquence : les IA et les joueurs te tuent toujours (le PvP reste actif selon les fiches de mode).
  • 🎯 Usage recommandé (communauté) : apprendre les spawns/routes d'une nouvelle carte, tester une arme que tu viens de modder, enchaîner les missions de saison, et faire des « lobby wipes » tranquilles avant de frapper les salles verrouillées.

Le cap 600 000 Koen

L'écran Equipment Value de ton loadout plafonne à 600k selon les retours S7 (400k dans les versions antérieures — le chiffre exact n'est jamais publié par MoreFun, vérifie la fiche du mode en jeu) :

  • ⚖️ Seul le gear PORTÉ compte — le sac à dos est ignoré, et le jeu bloque le contournement en interdisant d'emporter armure/casque dans le sac.
  • 🔧 La durabilité baisse la valeur : une armure T6 à 10-20 durabilité coûte une fraction de son prix neuf — c'est LE levier des joueurs qui affichent du T6 sous le cap.
  • 🤝 Répartition en squad (retours Steam/Reddit) : chaque membre porte une pièce chère puis se la passe après le spawn — l'équipe de 4 cumule ~1,2M de kits. ⚠️ contourner le cap autrement que par le loot in-raid est considéré comme un exploit selon les mods communautaires.
  • 📦 Astuce chargeur : ne monte pas le chargeur étendu sur l'arme — mets-le dans le gilet et recharge au spawn : tu gagnes 10-50k de valeur sous le cap (astuce reddit).

La fourchette large vient d'un artefact : l'estimation in-raid surévalue les armures abîmées (une T6 à 5 durabilité affiche 200k mais vaut ~30k ; à 0/100 elle ne rapporte rien). D'où les règles :

Maximise la conversion : 1. prends armes + attachements + objets de valeur (proches de leur vrai prix) · 2. laisse les plates sous ~50% de durabilité · 3. vise les Universal Key Cards (bon drop rate en Secure Ops) et utilise-les dans le même raid (les clés non utilisées ne rapportent pas) · 4. ne planifie jamais ton budget de Koen là-dessus — pour le vrai income, voir économie et Koen.

Loadouts recommandés

💰 Budget (400k)

SMG économique (PCC-9/MPX) + T4. Parfait pour enchaîner sans stress. Objectif : missions + 300-600k/semaine de conversion.

⚔️ Cap serré (600k)

Arme méta (A545/H416) + T5 porté, armure à durabilité contrôlée pour tenir sous le cap. Pour tester des builds avant le Lockdown.

🎓 Apprentissage

Kit jetable + carte neuve : spawns, routes d'exfil, salles verrouillées. Zéro gear fear = cerveau disponible pour apprendre.

Pour le détail des caps par mode Tactical (Normal T4 / Lockdown T5 + 900k) : tier list équipement · loadout optimizer.
